## Findings

### Does the diff contradict an accepted decision?

One contradiction was reproduced and repaired in this closing work unit.

The accepted merge sequence in `paths.md`, bedrock 22/35 and ADR-012 requires
the path to set its own `status: done` before it merges. Cairn's `branch-path`
rule nevertheless accepted only `running` on `path/*`, making the required
final state fail its own gate. The CP-RENDER-REPAIRS audit had already carried
this exact defect to CP-OPS-001. Closure now changes the allowed branch states
to `running | done` and adds the missing combined test: a `done` path with a
recorded ceremony passes `branch-path`, while the same transition without its
ceremony still fails. Draft, blocked, active and archived declarations remain
invalid work states for a path branch.

The rest of the rebased diff aligns accepted doctrine rather than changing it
silently. S08 makes the generated global view honest by registering the stable
path tuple on trunk before branching. S09 makes the already-required coherent
step remotely durable and independently resumable. Both are recorded in the
2026-08-24 amendment to ADR-012 and projected through the named bedrock pages.
No Electron boundary, provider surface, persisted product format, security
rule, or renderer contract changes in this path.
