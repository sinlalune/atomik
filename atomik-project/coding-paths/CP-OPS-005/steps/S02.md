# CP-OPS-005 S02

### S02 — repair — **COMPLETE**

#### Plan

Repair `steps/S01.md`, which was committed and pushed carrying the output of a
command that should never have run. A step record is append-only from the blob
that adds it, so the repair is a unit that names both blobs rather than an
amend to a published branch.

#### Work


Three passages of S01's Review section were damaged. The cause was mine and it
is mechanical: the record was written with `python3 -c "…"`, a **double-quoted**
shell string, so backticks inside it were command substitution. Bash ran them
before Python saw them.

```text
  **fixed**, and 14	21	atomik-project/coding-paths/CP-OPS-005/index.md
28	16	atomik-project/coding-paths/CP-OPS-005/steps/S01.md is quoted rather than…
```

That is `git diff --numstat`'s output, pasted into a protocol record by the
shell. Two more passages lost their backticked words entirely — `filed
upstream` and a `unit: 0` — leaving sentences with holes in them.

The three are restored to what they were meant to say. Nothing else in the file
is touched, and the `supersedes:` line names the blob the record was added with
and the blob it carries now, both read with `git`:

```bash
git log --diff-filter=A --format=%H -1 -- <file>   # a5fa051
git rev-parse a5fa051:<file>                       # c0d9d7d
git hash-object -- <file>                          # 956290e
```

#### Why this is a unit and not an amend

`pathHistoryPolicy: forbidden`. The commit carrying the damage is on
`origin/path/cp-ops-005`, and rewriting a published path branch is what
ADR-022 removed from this repository. The protocol's remedy for an edited
immutable record is a repair unit that binds both blobs, and this is it — the
first time this repository has needed one.

#### The lesson, and it is the fourth of its kind

Every heredoc in this session that used `<<'PY'` was safe; every one that used
`<<PY` or `-c "…"` to interpolate a shell variable exposed its backticks. It
happened three times before this and was caught each time in the working tree.
This time it reached a commit, a push, and an immutable record.

The rule that removes it: **write records with a quoted heredoc, and pass
values as `argv`, never by interpolating them into the script.**
