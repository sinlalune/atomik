# CP-OPS-003 S01

### S01 — the gate — **COMPLETE**

#### Plan

Delete the eight `tools/cairn-*.test.mjs`, the `cairn-check:test` script that
runs them and the workflow step that calls that script. It deliberately does
not adopt the release's own suite in their place, does not touch the tools
themselves, and does not touch product code.

Advances the first two items of the definition of done: no `npm run
cairn-check:test`, no workflow step calling it, and no `tools/*.test.mjs`
remaining.

#### Work

```cairn-unit
step: S01

type: implementation
verified: cairn-check (one blocking finding, external and named below)
```

- deleted `tools/cairn-{active,audit,check,config,fixture,init,rules,spec}.test.mjs`
  — 4 909 lines. Cairn 1.1 replaced all five reference tools at `37f56a5`;
  these are the 0.2 suite, dated `2026-09-02`, and ran 41 of 86 red against the
  installed engine. The kit ships its own suite and installs none of it
  (`REFERENCE_TOOLS`), deliberately: a host that owns no tools owns no tool
  tests.
- removed the `cairn-check:test` script from `package.json` and the line that
  names it from `binding.md`'s mechanical contract.
- removed the `validator self-test` step from `.github/workflows/cairn.yml`,
  and the `npm ci` above it, which existed only to install that suite's
  renderer dependency. The job's one remaining command imports node builtins
  and `tools/cairn-config.mjs`; the release's own installed workflow has
  neither step.
- unlinked `tools/cairn-rules.test.mjs` from
  `docs/cairn/cairn-protocol-round-3.md:317`. Deleting the file broke a
  relative link, which the `links` rule blocks on. **The principle this unit
  applied, and the one the review tested:** a deleted file is repaired where it
  is *linked*, never where it is merely *named*. Lines 36, 43 and 460 of the
  same brief name the suite in prose and a tree listing and are left exactly as
  written — they are a record of what was true in round 3.
- no product code, no tools, no tests of this product.
- the `scope-drift` advisory names 18 files outside `writes:` — `cairn.lock.json`,
  `cairn/README.md`, `docs/inputs/index.md`, the six `skills/**`. None were
  written by this unit. The adoption commit `37f56a5` has never reached the
  remote, so the branch's comparison against `origin/master` contains it, and
  those are its files. They leave the comparison the moment the trunk carries
  the adoption, which is blocked on the same registration this unit is.

#### Review

First read — reader: a fresh context, a subagent of this session, given the
diff and the two criteria and nothing else:

- `paths-history.md:415` still instructs `npm run cairn-check:test` — **refused.**
  That page's own banner reads *EXPLANATORY HISTORY, NOT THE CURRENT OPERATING
  ROUTE*, retained unabridged by ADR-020 stage 4 so the required reading can
  link its rationale instead of compressing it. Editing a captured page to
  match today is the defect the banner exists to prevent.
- `tools/cairn-check.mjs:2871` names `tools/cairn-fixture.test.mjs`, now
  deleted — **refused.** That comment is the kit's, and it is true in the
  repository the kit is cut from. Editing it widens the fork this repository is
  already carrying on that one file, which `cairn.lock.json` already reports as
  edited and ADR-023 is scheduled to record.
- the `round-3.md` repair is a half-fix: lines 36, 43 and 460 still cite the
  deleted suite, as do `docs/cairn/specification/reference/repository-layout.md`
  and the generated `specification.html` — **refused for the brief, deferred
  for the copy.** The brief is prose and a tree listing, not links, and the
  gate does not block on them; see the principle in the work block. The
  specification copy and its generated HTML are the 0.2 specification, which
  **S02 deletes whole** — repairing citations inside a folder this path removes
  is work with no reader.
- the new workflow comment cites `tools/cairn.mjs`, which is not in this
  repository — **fixed.** The comment no longer names a file this host does not
  have.
- the retained `npm ci` is dead weight and the sentence defending it is wrong:
  jobs run on separate runners, nothing is shared with `gates` — **fixed**, and
  independently found in the self-review above before this read returned.
- seven lines of comment narrating a deleted step is commit-message material —
  **fixed**, cut to four.
- the `round-3.md:317` edit replaced a dead link with ticket bookkeeping —
  **fixed**, the parenthetical is dropped entirely.
- deletion is safe on the executable side: nothing runs `node --test` over
  `tools/` any more, and `cairn.lock.json`'s manifest lists no `*.test.mjs` —
  no finding.
