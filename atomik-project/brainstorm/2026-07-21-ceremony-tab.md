# Ceremony tab (provisional — nothing here is a decision)

Owner, while refining the path-transition process (2026-07-21): *"Tab
should be a better way to organize that ceremony I guess followed by
prompted exchange with me?"*

The idea: the CLOSING ceremony and OPENING check (22 §Between paths)
render as an Atomik TAB instead of living only in chat — the recall
of everything done (derived from the register, ledgers, acceptance
records and log), the backlog as it stands, the candidate next paths,
and the prompted questions themselves, answerable in-app; answers
land in the session note exactly as the chat flow does today.

Doctrine fit: bedrock 35 §Interactive artifacts already reserves this
shape — "Atomik may render an active coding path as a progress bar,
macro checklist, dependency view…: files contain the state, the
artifact arranges and edits references to it, closing the artifact
loses nothing." A ceremony tab is that projection pointed at the
execution-state plane's TRANSITIONS instead of a single path.

Open questions for whenever a path picks this up:

- Data source: read the register/ledger markdown directly, or a
  generated sidecar?
- Answer capture: edits into the session note through the normal
  patch flow?
- Does the AI seat drive the prompted exchange in-app (needs
  CP-MVP-008's surfaces), or does the tab only PRESENT while the
  exchange stays with the coding agent?

Until then the ceremonies run as prompted exchange in chat + session
notes (the 2026-07-21 instances are the reference examples).
