# Sources

Where an imported spec, paper or reference would live if this plane ever needed
one: as a `source.md` dossier beside its raw asset, recording provenance,
extraction and anchors
([ADR-002](../../docs/adr/ADR-002-markdown-source-dossiers.md),
[bedrock 07](../../docs/bedrock/07_07-source-adapters.md)).

**Empty so far, and that is meaningful rather than missing.** Everything this
plane has needed has been either a durable decision (`docs/adr/`), doctrine
(`docs/bedrock/`), dated external evidence (`docs/research/`) or execution state
(`coding-paths/`). External material read once and cited belongs in a research
note; material Atomik should be able to re-read, anchor and quote belongs here as
a dossier.
