# CP-MVP-009 S07 form rulings (2026-08-13)

The owner returned from vacation and asked where the path stood and
what remained to validate. S07 (drafted as "typed backlinks pane")
had three open design calls that would change the work, so they were
put before the owner BEFORE any code — the mid-path equivalent of the
opening check's delta rule (22 §Between paths). Answers verbatim
below; the path's S07 step was amended to match in the same work unit.

## The three calls

1. **Placement** → the owner did not take any offered option and
   answered with a question, verbatim: **"yes but why not directly an
   ontology in a canvas ?"**

   Answer given, from the record rather than from taste: the canvas
   IS on the books and reads THIS index — brainstorm 2026-08-04
   ("vault graph: canonical = note files; the canvas PROJECTS the
   nodes/edges index"), the CP-MVP-009 opening check ("the studio is
   recorded as a later consumer of the nodes/edges index"), and
   bedrock 21 (canvas = projection layer over files). It is not S07
   because of cost (one custom engine — the owner's own ruling
   replacing the Excalidraw embed — with selection, undo, layers,
   groups, hit-testing rebuilt by hand: a multi-month track on the
   brainstorm's own honest-cost line), because 21 sits in this path's
   Deliberately-excluded list, and because the two answer different
   questions (a canvas = "what does this region look like", a strip =
   "who leans on the note I am reading, right now").

   A middle option was then offered and **chosen**: a **1-hop
   mini-graph in a bottom strip** — this note centered, neighbours
   around it, labelled edges, click to open, NO persisted layout
   (positions recomputed from the index every render). It is the
   note-scale v0 of the studio's graph layer: same index, same read
   contract; the studio later replaces the renderer, not the data.

2. **Inverse reading** → **"Keep the written label"**: the relation
   reads with the other note as subject and the label exactly as
   authored ("L'ethos — repose sur — this note"). No invented inverse
   phrasing; ADR-011 keeps "inverse reads as …" available as later,
   optional label-registry metadata.

3. **Vault-wide broken-links list** → **"Wait for a later path"**:
   the dashed pill stays the only diagnostic. S06's deviation is
   carried forward, not closed. (Context given at the time: the dev
   vault's index reported 0 broken links, so there was nothing to
   hunt yet.)

## What this changes downstream

- S07 shipped as a mini-graph strip; the path's definition-of-done
  line "typed backlinks pane per note shows inbound edges" is met by
  the strip (inbound AND outbound, labels as authored) — the wording
  predates the ruling and is read as satisfied, not as unmet.
- The studio path inherits a working consumer of the index to
  generalize from, plus the rule that layout is canvas-owned state
  while the graph itself stays in the files.
- The broken-links diagnostic remains an open backlog item for the
  closing ceremony's recall.
