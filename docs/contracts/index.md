# Contracts

Machine-readable mirrors of contracts whose prose home is a bedrock page. The
bedrock page is canonical; a mirror exists so tools and agents can read the shape
without parsing prose. When the two disagree, the bedrock page wins and the
mismatch is a defect to repair, not a variant to keep.
