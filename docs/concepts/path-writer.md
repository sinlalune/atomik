# Path writer

The path writer changes implementation, tests, affected documentation, ledger,
and [handoff](./handoff.md) as one coherent [work unit](./work-unit.md).

Only one writer is assigned to the writable path [worktree](./worktree.md) at a time. The role
can pass between developers or agents at a pushed checkpoint; it is not
permanent ownership of the path. Other participants may inspect or review
without becoming its writer.

Related: [writer assignment](./writer-assignment.md),
[work unit](./work-unit.md), [handoff](./handoff.md).
