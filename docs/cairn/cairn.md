Concerning Cairn Protocol :

# History

Cairn protocol has been emerging trough the distillation of ideas leading to creation of documentation for initialasing atomik project.
It had been used for brainstorming through multiple session before the existence of /brainstorm in many AI app.
The only persisting format was a series of md files known as bedrock and an html indexes.*
Then appeared others docs in the distillation before the start of implementation.

We then thought that it would be interesting that the coding agent that will implement it will be bounded to use those docs to build it, so we created the /***-project directory for both referencing the docs to implementation but also generating useful content from it that could be reffered to after.
All of that almost undirectly injected harness agnosticism into it, because the project details and evolution doesnt dies in sesssion anymore, the most important essence of it persist as Cairns to help the user and the agent to situate.

Through the project, many docs have been updated, concerning the project itself but also and most importantly in our case, concerning th protocol.

We tried our best to respect OKF protocol, but looking at all directories, it hasnt been set everywhere.
