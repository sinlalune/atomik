# History

We have been building the protocol through empirical approach since the beginning via the atomik project.

Some of it is good some of is seems a little bit overkill.

So, to be sure that we are following a vision, I wrote the cairn-manifesto, so we can have step back reflexion moment about what we built.

I think the next step is to look at the protocol in its current state and apply the manifesto to it, by auditing it and optimizing it through the manifesto vision.

In addition to manifesto convergence, We also need to proof the protocol through the latest coding workflow, to be sure we are not a protocol that is already out of date.
For exemple the study of the necessity of graph based agentic coding workflow, the inspiration of ponytail skills guide lines, etc...


# My goals
