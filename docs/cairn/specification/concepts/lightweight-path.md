# Lightweight path

A lightweight path is a planned protocol profile for small, low-risk changes
whose coordination cost would otherwise exceed their implementation cost.

It must define objective eligibility, preserve durable intent and
[remote checkpointing](./remote-checkpoint.md), state which ceremonies combine,
and prevent a large or risky
change from self-declaring itself lightweight.

Cairn v0.1 does not implement this path. Ordinary paths MUST NOT bypass current
requirements by using the name.

Related: [conformance](./conformance.md), [coding path](./coding-path.md),
[emergency path](./emergency-path.md).
