# Path initiator

The path initiator turns an intent into a proposed bounded outcome, definition
of done, initial steps, knowledge coverage, expected writes, and exclusions.

The initiator may be a developer, coding agent, domain specialist, or another
authorised participant. [Opening acceptance](./opening-acceptance.md) evaluates
the proposal; initiating it does not grant automatic authority to accept it.
