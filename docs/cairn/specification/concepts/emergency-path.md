# Emergency path

An emergency path is a planned route for urgent work where waiting for the
ordinary sequence would create greater immediate harm.

It must define who can invoke it, what minimum checks and
[remote](./remote.md) records remain mandatory, how the exception is visible,
and when deferred audit and
documentation are completed.

Cairn v0.1 does not implement this route. “Urgent” is not permission to omit
state silently.

Related: [conformance](./conformance.md), [coding path](./coding-path.md),
[lightweight path](./lightweight-path.md).
