# Emergency path

An emergency path is a planned route for urgent work where waiting for the
ordinary sequence would create greater immediate harm.

It must define who can invoke it, what minimum checks and
[remote](./remote.md) records remain mandatory, how the exception is visible,
and when deferred audit and documentation are completed.

Cairn v0.2 does not implement this route, and it is not a synonym for the
[lightweight path](./lightweight-path.md): lightweight reduces ceremony for
changes that were always small, while an emergency route defers evidence for
changes that may be large. "Urgent" is not permission to omit state silently.
