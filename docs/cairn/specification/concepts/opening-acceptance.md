# Opening acceptance

Opening acceptance is an authorised decision that a proposed
[coding path](./coding-path.md) is clear enough to register and execute.

## In Cairn

Participants review the intended outcome, definition of done, steps, required
knowledge, exclusions, declared writes, and initial writer. A session record
names the path, accepted decision, actor, UTC time, and scope reference before
the registration commit lands.

The repository's governance defines who may accept. Cairn does not require one
permanent owner.

## It does not prove

Opening acceptance authorises a plan; it does not accept implementation that
does not yet exist.
